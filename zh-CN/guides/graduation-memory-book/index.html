毕业纪念册怎么做：内容、设计和在线制作方法

毕业季，最舍不得的是一起度过的日子。毕业纪念册把班级合照、日常照片、同学留言和老师的寄语收在一起。除了纸质版，做一本电子毕业纪念册，还能加入视频和每个人的声音，用一个链接就能随时打开。

毕业纪念册放什么内容

  • 班级合照和每位同学的照片。
  • 日常瞬间：课间、运动会、军训、春游、元旦晚会。
  • 同学留言和班主任寄语。
  • 视频片段：毕业晚会、最后一节课。
  • 语音祝福：每人录一句想对大家说的话。

封面和内页设计思路

  • 封面：班级合照 + 班级名称 + 毕业年份。
  • 按时间分章：高一、高二、高三，或大一到大四。
  • 按活动分章：军训、运动会、晚会、毕业典礼。
  • “每人一页”：一张照片、一句话、一段语音。
