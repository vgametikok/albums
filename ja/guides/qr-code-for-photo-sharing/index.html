写真共有用のQRコード：ゲストがアップロードできるコードの作り方

写真共有用のQRコードがあれば、イベントに来た誰もが印刷されたコードを読み取って、写真をひとつの共有アルバムにアップロードできます。結婚式、パーティー、親族の集まり、社内イベントの写真を集めるいちばん簡単な方法です。ただし、正しく設定すれば。このガイドでは、作り方、無料の方法と専用のイベントアルバムの比較、ゲストがアップロードしなくなってしまうよくある失敗を紹介します。

写真共有用のQRコードとは？

QRコードは、短いテキスト、たいていはウェブアドレスを記録した四角いバーコードです。写真共有用のQRコードには、アップロードページのアドレスが入っています。ゲストがスマホのカメラを向けると、そのページを開くよう提案が表示され、ゲストは写真や動画を選んでアップロードします。

ここから、2つのことがわかります。

  • コードには写真は入っていません。コードは倉庫ではなく扉です。大切なのは、その先にあるページです。
  • ゲストの体験は、そのページで決まります。ログイン、アプリのダウンロード、わかりにくいフォルダの権限を求められると、多くのゲストがあきらめます。

写真共有用のQRコードのしくみ

  1. 行き先を用意します。共有フォルダ、またはアップロードページのあるイベントアルバムです。
  2. そのリンクをQRコードにします（専用サービスなら自動でやってくれます）。
  3. コードをサイン、カード、招待状に印刷するか、画面に映します。
  4. ゲストはiPhoneやAndroidの標準のカメラアプリで読み取ります。
  5. ゲストは写真や動画を選んでアップロードし、共有アルバムに表示されます。
  6. イベントのあとで、確認、整理、ダウンロードをします。

無料の写真共有用QRコード：ジェネレーター＋クラウドフォルダ

自分で作る方法なら、費用はかかりません。

  1. Googleドライブ、Googleフォト、Dropbox、iCloudで共有フォルダまたはアルバムを作ります。
  2. リンクを知っている人がファイルを追加できるよう、共有設定を変更します。
  3. リンクをコピーして、無料のQRコードジェネレーターに貼り付けます。
  4. 画像をダウンロードして印刷します。

これでも使えますが、次の点に注意してください。

  • アカウント。GoogleフォトやGoogleドライブでは、たいてい寄稿者のログインが前提です。iCloud共有アルバムでは、Androidユーザーはまったくアップロードできません。詳しくはiPhoneとAndroidで使える共有フォトアルバムをご覧ください。
  • 期限切れになるダイナミックコード。多くの「無料」ジェネレーターは、自社のサーバーを経由するダイナミックコードを作り、お試し期間のあとに使えなくなります。印刷したサインは、どこにも行けなくなります。スタティックコード、またはアルバムサービスが提供するコードを使いましょう。
  • 誰でも編集できる状態。編集可能なフォルダのリンクを持つ人は、たいてい他の人のファイルを削除したり名前を変えたりできます。
  • モデレーションなし。アップロードはすべてそのまま見えてしまいます。

Googleフォトのアルバムと、QRゲストアルバムのさらに詳しい比較は、Googleフォトとの違い（QRゲストアルバム）をご覧ください。

イベントアルバムでの写真アップロード用QRコード

専用のイベントアルバムは、ゲスト用のアップロードページを中心に作られています。

  • QRコードはアルバムと一緒に作られ、アルバムがある間は使えなくなりません。
  • ゲストはアプリもアカウントもなしに、ブラウザからアップロードします。
  • 写真を表示する前に承認を必須にできます。
  • 写真ごとに、全員に公開、友だちだけに限定、非表示を選べます。
  • イベント中にアルバムをテレビで開けば、みんなが写真を見られます。
  • すべてをひとつのZIPでダウンロードできます。

Albumsでは、持ち主が写真のそばにボイスノートも追加でき、アルバムがファイルの山ではなく物語になります。

そのまま使える写真共有用QRコードを手に入れる

イベントアルバムを作成すれば、印刷用のQRサインをすぐにダウンロードできます。ゲストはどのスマホのブラウザからでもアップロードできます。アプリも登録も不要です。

写真共有用QRコードの作り方：印刷する前に

  • 画面だけでなく印刷したものを、少なくともiPhone1台とAndroid1台で読み取ります。
  • テスト用の写真をアップロードして、想定した場所に届くか確認します。
  • サイズを確認します。手に持つカードなら3×3 cm以上、テーブルサインなら8〜10 cm、遠くから見るポスターならさらに大きく。
  • コントラストを高く保ちます。明るい背景に濃い色のコード、そのまわりにクワイエットゾーン（余白）を。
  • デザインしすぎないこと。中央のロゴや色付きのコードは、読み取りを妨げることがあります。
  • コードの下に短いリンクを添えます。カメラで読み取れない人のために。
  • 案内を一行添えます：「カメラで読み取って写真をアップロード。アプリは不要です」。

写真共有用QRコードの置き場所

  • 結婚式やパーティーでは、入口にひとつではなく、すべてのテーブルに。
  • ケーキ、バー、フォトブース、ダンスフロアの近くなど、すでにスマホが出ている場所に。
  • 招待状、プログラム、イベントのウェブサイトに。
  • 会場の画面の、スライドの合間に。
  • カンファレンスの名札やスライドに。
  • イベントのグループトークやフォローアップのメールに、リンクとして。

文言の例は、結婚式のQRコードテーブルサインのアイデアとパーティーの写真用QRコードをご覧ください。

QRアルバムを安全に保つ

コードを読み取った人は誰でもアップロードページにたどり着けるので、誰がコードを見るかを考えましょう。

  • アルバムが非公開なら、コードをSNSで公開投稿しないでください。
  • 公開イベントや大規模なイベントでは、承認をオンにします。
  • アルバムは非表示にして、どこにも一覧表示されず、リンクを知っている人だけが開けるようにします。
  • イベントのあとで、全員に見せる写真と非公開のままにする写真を決めます。

よくある失敗

  • イベント後に期限切れになるお試しのQRコードを使う。
  • GoogleやAppleのアカウントが必要なフォルダにリンクする。
  • コードが小さすぎる、コントラストが低い、背景がごちゃごちゃしている。
  • 入口にサインを1枚置いて、テーブルには置かない。
  • アプリが不要だとゲストに伝え忘れる。
  • イベント中にアルバムのことを一度も話さない。

写真共有用のQRコードは無料？

QRコードを作るのは無料です。お金がかかるのは、写真を保管し、アップロードを簡単にすることです。Albumsでは、Event Albumはイベントごとの買い切りで39.99ドルから（Smallプラン、100人までのゲストにおすすめ）、税込みで、ゲストの支払いはありません。イベントアルバムの保存期間は最初のアップロードから6か月で、さらに6か月延長でき、いつでもすべてをZIPでダウンロードできます。

  • 期限切れにならないQRコードを作る
  • 印刷してiPhoneとAndroidで試す
  • 案内文と短いリンクを添える
  • スマホが出る場所にコードを置く
  • 大規模または公開イベントでは承認をオンにする
  • イベントのあとでZIPをダウンロードする

よくある質問

写真共有用のQRコードはどう作りますか？

アップロードページのある共有アルバムを作り、そのリンクのQRコードを生成し（イベントアルバムのサービスでは自動です）、印刷してiPhoneとAndroidで試します。

無料の写真共有用QRコードはありますか？

はい。無料のジェネレーターと、Googleドライブ、Googleフォト、Dropboxの共有フォルダの組み合わせです。引き換えに、ゲストのアカウント、期限切れになるダイナミックコード、モデレーションがない点があります。

QRコードを読み取るのにアプリは必要ですか？

いいえ。最近のiPhoneやAndroidのカメラはQRコードを読み取れますし、よくできたアップロードページはブラウザで開きます。

写真用のQRコードは期限切れになりますか？

スタティックコードは期限切れになりませんが、一部の無料ジェネレーターのダイナミックコードは、お試し期間のあとに使えなくなります。イベントアルバムのコードは、アルバムがある間は使えます。

写真用QRコードの大きさはどのくらい？

テーブルサインなら約8〜10 cm、遠くから見るポスターならさらに大きく、いつもコントラストを高くします。
