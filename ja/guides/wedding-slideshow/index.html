結婚式のスライドショー：写真の枚数、長さ、曲の選び方

結婚式のスライドショーは、会場全員が同じスクリーンを見て、一緒に笑い、感動し、拍手する数少ない時間です。うまく作れば数分でふたりの物語が伝わり、失敗すると長すぎてゲストがスマホを見始めます。このガイドでは、写真の枚数、長さ、曲の選び方、使える無料ツール、そして自分で作るスライドショーのために家族やゲストから写真を集める方法を紹介します。

結婚式スライドショーの2つのタイプ

多くの披露宴では、どちらか、または両方を使います。

  • 生い立ちムービー。子ども時代から婚約までの写真で作る映像で、食事の後や入場前など決まったタイミングで一度だけ流します。
  • サンクスムービー。結婚式の後、ゲストの写真で作り、全員に送ったり、翌日のブランチや1年目の記念日に流したりします。

前者はふたりの過去、後者はその日そのもの。どちらにも必要なのは、すべての写真が一か所に集まっていることです。

写真は何枚、長さはどれくらい？

いちばん多い失敗は写真の入れすぎです。目安は1枚あたり5〜7秒。

  • 3分（1曲）：約30〜35枚
  • 6〜8分（2曲）：約60〜80枚
  • 10分：約100枚。多くの会場ではこれが上限です

生い立ちムービーなら6〜8分がベスト。10分を超えると、特にお酒が入った後は集中が切れます。使いたい写真がもっとあれば、サンクスムービーやオンラインアルバムに回しましょう。

うまくいく構成

短い映画をチャプターに分けるイメージです。

  1. 子ども時代：それぞれ8〜12枚、ふたり交互に。
  2. 学生時代と友人：懐かしい髪型、修学旅行、会場にいる友人たち。
  3. 出会い：初めてのツーショット、初デート、思い出の場所。
  4. ふたりの日々：旅行、ペット、新居、家族との時間。
  5. プロポーズと婚約：力強く幸せな1枚で締めくくります。
  6. エンディング：「今日は来てくれてありがとう」、ふたりの名前と日付。

各チャプター内は時系列に並べます。家族やゲストの写真を入れると、誰もが大きなスクリーンで自分を見つけて喜び、最後まで見てくれます。

曲の選び方

  • 全体で1〜2曲に。1分ごとに曲が変わると落ち着きません。
  • 子ども時代は穏やかに始め、プロポーズに向けて盛り上げます。
  • ふたりにとって意味のある曲を選びつつ、歌詞が家族の前でも問題ないか確認しましょう。
  • 最後は曲をぶつ切りにせず、フェードアウトで。
  • 結婚式場で流す場合や後でネットに公開する場合は、楽曲の著作権手続きが必要なことがあります。会場に事前に確認しましょう。

スライドショーを作れる無料ツール

専用ソフトは不要です。人気の選択肢：

  • Googleフォト：写真を選んでムービーを作り、音楽を追加。手軽で簡単。
  • iMovie（iPhone、iPad、Mac）：無料で、トランジション、タイトル、細かなタイミング調整が可能。
  • Canva：ブラウザで使えるテンプレート。文字カードや音楽も。
  • PowerPointやKeynote：スライドを自動で切り替える設定にして、動画として書き出し。
  • CapCutなどのスマホ編集アプリ：スマホで手早く編集したいときに。

どのツールでも、動画ファイル（MP4）で書き出し、会場の実際のスクリーンで試写しましょう。

スライドショー用の写真を集めよう

家族やゲストはQRコードを読み取り、スマホのブラウザからアップロード。あなたはZIPで一括ダウンロード。アプリも登録も不要です。

家族から昔の写真を集める

いちばん大変なのは写真探しです。親はプリント写真を箱にしまい、兄弟姉妹は古いスマホにデータを持ち、友人は恥ずかしい写真を持っています。一人ずつメッセージで頼む代わりに：

  1. 共有のオンラインアルバムを作り、リンクかQRコードを家族や親しい友人に送ります。
  2. 「赤ちゃんの頃」「学生時代」「ふたりの写真」のように、チャプターを指定して頼みます。
  3. 親には、昔のプリント写真を明るい自然光の下で、まっすぐ、反射なしでスマホで写真に残してもらいます。
  4. 編集の時間を確保するため、締め切りは結婚式の約3週間前に。

QRアルバムは当日も使えるので、同じリンクで後からゲストの写真も集まります。詳しくは写真共有用のQRコードへ。

サンクスムービー用のゲスト写真

ゲストのスマホには、集めなければ見ることのない写真がたくさんあります。イベントアルバムでの流れ：

  1. アルバムを作り、QRコードを席札や受付の案内板に印刷します。
  2. 司会のアナウンスや招待状で触れ、どこにアップロードすればいいか伝えます。
  3. ゲストは読み取って写真や動画を選び、スマホのブラウザからアップロード。
  4. 写真をチャプターに分け、ほかの人に見せたくない写真は非表示にします。
  5. 結婚式の後、すべてをZIPでダウンロードし、ベストな写真をスライドショー作成ツールに取り込みます。

ゲストの写真で作るサンクスムービーは、カメラマンが見ていなかった角度からその日を見せてくれ、全員への素敵な贈り物になります。ツール選びは結婚式の写真共有アプリも参考に。

それぞれのスライドショーを流すタイミング

  • 結婚式の前：生い立ちムービーの短い予告をウェブ招待状などで。
  • 食事の後やお色直しの入場前：生い立ちムービーを一度だけ、照明を落として静かな中で。
  • 結婚式の後：ゲストの写真で作るサンクスムービーを、お礼のメッセージと一緒に送るか、ブランチで流します。

司会者に生い立ちムービーの紹介を頼み、前日までに会場の音響とスクリーンで通しの試写をしておきましょう。

結婚式スライドショーに使えるAlbums.ink

  • ゲストはブラウザからアップロード：アプリもアカウントも不要。
  • iPhoneとAndroidから写真も動画も。
  • ゲストの写真は最大4K（長辺3840px）で保存。
  • どの写真も非表示にでき、写真ごとに公開範囲を設定。
  • アルバムを整理するチャプターと、写真に添えるオーナーのボイスメモ。
  • イベント（QR）アルバムの保存期間：最初のアップロードから6か月、延長可能。ZIPで一括ダウンロードできます。
  • 買い切り料金：Small 39.99ドル（100人までにおすすめ）、Medium 69.99ドル、Large 129.99ドル。ゲストは無料です。比較は写真共有アプリのおすすめで。

よくある失敗

  • 写真が多すぎて10分を超える。
  • 解像度が低く、大きなスクリーンでぼやける。
  • 会場でファイル、音響、スクリーンを試していない。
  • 新郎新婦の写真ばかりで、ゲストの写真がない。
  • 音楽がスピーチには大きすぎる、または小さすぎて聞こえない。

チェックリスト

  • 生い立ちムービー、サンクスムービー、または両方を決める
  • 家族の写真は3週間前までに集める
  • 写真60〜80枚と曲1〜2曲を選ぶ
  • MP4で書き出し、会場のスクリーンで試写する
  • アルバムのQRコードを印刷し、後ですべてダウンロード

よくある質問

結婚式のスライドショーの長さはどれくらいがいい？

6〜8分、つまり1〜2曲程度です。10分を超えると会場の集中が切れがちです。

結婚式のスライドショーには写真が何枚必要？

1枚5〜7秒が目安。3分なら約30〜35枚、6〜8分なら60〜80枚です。

披露宴ではいつスライドショーを流す？

生い立ちムービーは食事の後や入場の直前がおすすめ。ゲスト写真のサンクスムービーは、翌日のブランチやゲストへのメッセージにぴったりです。

スライドショー用にゲストの写真を集めるには？

イベントアルバムを使います。ゲストがQRコードを読み取ってブラウザからアップロードし、あなたはZIPでダウンロードしてスライドショーに使います。

結婚式のスライドショーを無料で作るには？

Googleフォト、iMovie、Canva、PowerPointで作れます。MP4で書き出し、会場で試写しましょう。
