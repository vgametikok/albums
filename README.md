# Albums

Соцсеть, где единица контента — **альбом**: курируемая коллекция фото, видео и голосовых
заметок, которая читается как история. Плюс вторая поверхность — инста-стайл лента постов
(пост = фото/видео или карусель).

Прод: https://albums.ink

## Стек

Статика без сборки (HTML + ES-модули) на Cloudflare Pages, данные — Supabase
(Postgres + RLS, вход через Google и Telegram, R2 для медиа, SECURITY DEFINER RPC).
Архитектура, планы и стратегия — в приватном репозитории документации (`internal/`).

## Публикация

**Боевой сайт собирается Jekyll по `_config.yml`** — проверено 2026-09-01
запросами к albums.ink: закрыто ровно то, что перечислено в его `exclude`.
`node build.mjs` в облаке НЕ выполняется, поэтому:

* список `SKIP` внутри `build.mjs` на публикацию не влияет — правьте
  `_config.yml`;
* версии `?v=` к скриптам (защита от рассинхронизации HTML и JS после
  выкладки) не проставляются;
* `sitemap.xml` с публичными альбомами обновляется только когда кто-то
  запустит сборку локально и закоммитит результат;
* `wrangler.jsonc` и `src/index.js` не в деле: Worker не запускается, и
  превью ссылок в мессенджерах отдают общую заглушку вместо названия
  альбома.

Чтобы всё перечисленное заработало, в Cloudflare нужно задать команду
сборки `node build.mjs` и каталог вывода `dist`.

Локальная сборка (раскладывает публикуемые файлы в `dist/`, прошивает
SEO-блоки и проставляет версии):

```
node build.mjs
```

`tools/build-head.mjs` правит SEO-блоки прямо в исходных `.html`, поэтому
результат его работы коммитится и на боевом сайте живёт независимо от того,
чем собирают.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Лента рекомендаций альбомов + поиск (`?q=`) |
| `album.html?id=` | Альбом: обложка, главы, медиа, голосовые заметки, комментарии |
| `posts.html` | Инста-лента постов + композер карусели |
| `profile.html?u=` | Профиль, дружба, сетка альбомов |
| `editor.html?id=` | Создание/редактирование альбома |
| `friends.html` | Заявки, друзья, поиск людей |

## Приватность

Альбом виден: всем (`public`) / только автору (`private`) / друзьям (`friends`) /
друзьям кроме выбранных (`friends` + `album_exceptions`). Всё считает **одна** функция
`can_view_album()`, на которую опираются RLS-политики, политики Storage и фид-RPC.
Медиа лежат в приватном бакете и отдаются подписанными URL — приватный альбом
нельзя открыть по угаданной ссылке.

## Локальная разработка

```
node serve.js          # http://localhost:5085
```

## Миграции

Схема живёт в `supabase/migrations/`. Применение (нужен `.supabase-token` в корне,
он в `.gitignore`):

```
powershell tools\sql.ps1 -Path supabase\migrations\001_init.sql
```
